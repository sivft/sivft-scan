# Security

sivft-scan is designed to run on your own machine against your own log
samples. It makes no network calls and sends no data anywhere.

## Reporting a vulnerability

If you find a security issue — anything that could cause data to leave the
machine, execute untrusted input, or crash unexpectedly — please report it
privately before disclosing it publicly.

Open a [private vulnerability report](https://github.com/sivft/sivft-scan/security/advisories/new)
or email security@sivft.com. Include:

- A description of the issue and its impact
- Steps to reproduce, or a minimal test case
- Any suggested fix, if you have one

You should receive an acknowledgement within 48 hours.
